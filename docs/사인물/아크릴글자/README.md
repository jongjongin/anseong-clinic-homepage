# 아크릴 글자 발주 도면

브로애드(아크릴 글자 업체) 발주용 1:1 실측 파일입니다. 총 15개 조각.
글자 5개, 베드번호 숫자 3개, 일자 막대 3개, 「좌」 4개.

## 파일 두 개의 용도가 다릅니다

**`아크릴글자_커팅용.ai`** — 업체에 보내는 파일입니다.
실제로 자를 15개 조각만 들어 있고 치수선·설명글은 하나도 없습니다.
모든 글자는 윤곽선(아웃라인) 처리된 벡터 도형이라 글꼴 설치 없이 바로 커팅됩니다.
1230 x 813 mm, 도형 15개 (= 조각 수와 동일).

**`아크릴글자_도면_치수표기.ai`** — 치수 확인용 참고 도면입니다.
각 조각의 세로 높이와 가로 폭, 항목 번호, 주의사항이 적혀 있습니다.
커팅 대상이 아니므로 업체에는 참고용으로만 전달하세요.

`.pdf`는 같은 내용을 누구나 열어볼 수 있게 한 것이고, `미리보기_*.png`는 그림입니다.

## 아웃라인 검증 결과

두 파일 모두 아래 항목을 프로그램으로 확인했습니다.

| 항목 | 커팅용 | 치수 도면 |
|---|---|---|
| 글자(TEXT) 객체 | 0개 | 0개 |
| 도형(PATH) 객체 | 15개 | 141개 |
| 글꼴 참조 | 없음 | 없음 |
| 글꼴 파일 임베드 | 없음 | 없음 |
| 글자 출력 명령(Tj/TJ) | 0개 | 0개 |

커팅용의 도형 15개는 실제 조각 수와 정확히 일치합니다.
검증은 `make_sign.py` 실행 후 `analyze.py`와 같은 방식으로 재현할 수 있습니다.

## 글꼴

지정 글꼴(Sandoll 고딕Neo Cond, MICE명조)은 유료라 업체도 보유하고 있지 않아,
무료 글꼴로 만든 뒤 윤곽선 처리했습니다.

- 고딕 자리: Noto Sans KR Regular
- 명조 자리: Noto Serif KR Regular

둘 다 SIL Open Font License 무료 글꼴로 상업적 사용과 간판 제작에 제한이 없습니다.

## 다시 만들기

```
pip install fonttools reportlab
# 스크립트와 같은 폴더에 NotoSansKR-Regular.ttf, NotoSerifKR-Regular.ttf 를 두고
python3 make_sign.py     # out/ 폴더에 커팅용·치수표기 파일이 함께 생성됨
```

글꼴은 Google Fonts(Noto Sans KR / Noto Serif KR)에서 내려받을 수 있습니다.
