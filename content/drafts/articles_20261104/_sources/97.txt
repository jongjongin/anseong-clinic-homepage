체중이 더 이상 감소하지 않아 좌절을 느끼는 경우도 많습니다.
이 현상은 신체가 변화를 생존 위협으로 인식해 대사 속도를 늦추고 에너지 소비를 줄이는 자연스러운 반응 때문입니다.

이를 해결하기 위해 Set Point Theory와 Settling Point Theory를 알아보겠습니다.
Set Point Theory와 Settling Point Theory란?
Set Point Theory란
Set Point Theory는 우리 몸이 특정 체중을 유지하려는 기본 메커니즘이 있다는 개념입니다.
체중이 줄어들면 대사가 느려지고 식욕이 증가하며, 이는 본래 체중으로 돌아가려는 몸의 자동 반응입니다.
이 때문에 체중 감량 과정에서 정체기가 나타나는 것입니다.
Settling Point Theory란
반면, Set Point Theroy에서 더 진화된 Settling Point Theory는 환경과 행동 변화가 체중 조절에 영향을 미칠 수 있다고 주장합니다.
예를 들어, 식습관이나 운동 습관의 변화를 통해 새로운 균형점을 설정할 수 있습니다.
이는 정체기를 극복하고 체중을 줄이는 데 강력한 힌트를 제공합니다.
